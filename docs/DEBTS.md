# Долги

Долги разделены на:

- `TheyOweMe` — мне должны;
- `IOwePerson` — я должен человеку;
- `BankLoan` — банковский кредит;
- `CreditCard` — задолженность по кредитной карте.

Для позиции показываются первоначальная сумма, остаток, погашенная сумма, контрагент, сроки и влияние на финансовое состояние.
