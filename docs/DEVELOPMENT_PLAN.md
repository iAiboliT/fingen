# План разработки FingenNext

## Этап 1. Рабочее ядро MVP
- Финансовая доменная модель: счета, операции, категории, долги, кредиты, кредитные карты.
- Единый расчет баланса: доступные деньги, активы, обязательства, чистый капитал.
- Явные сценарии долгов: «дал в долг», «мне вернули», «взял в долг», «я вернул».
- Кредитные карты: шаблоны условий, расчет грейса, минимального платежа и ориентировочных процентов.

## Этап 2. Локальное хранение
- Room entities/DAO/repository.
- Мапперы между domain и data.
- Seed-данные для первого запуска и демо-режима.

## Этап 3. Современный UI
- Dashboard с разделением «доступно» и «чистый капитал».
- Операции: быстрый ввод расхода/дохода/перевода.
- Долги: карточки «мне должны» и «я должен».
- Кредитки: понятный экран грейса и следующего платежа.
- Отчеты: расходы по категориям, динамика, прогноз платежей.

## Этап 4. Парсинг банковских сообщений
- Android Notification Listener вместо устаревшего SMS-only подхода.
- Настраиваемые правила парсинга.
- Подтверждение пользователем перед созданием операции.
- Связка операции с QR/ФНС-чеком.

## Этап 5. Импорт, экспорт, резервные копии
- CSV/JSON экспорт.
- Локальные encrypted backups.
- Миграция из старого Fingen после анализа формата базы/экспорта.


> Development branch: `fingen-next`.
