# FingenNext — модель данных

## Счета

`AccountEntity` хранит тип, валюту, дату начала и opening balance. Текущий баланс вычисляется через ledger.

## Операции

`TransactionEntity` — бизнес-событие. `LedgerEntryEntity` — денежные изменения счетов, связанные с операцией.

## Долги

`DebtEntity` хранит первоначальную сумму, остаток, сторону обязательства, даты и статус.

## Кредитные карты

`CreditCardTemplateEntity` хранит пользовательскую версию правил. Изменение новой версии не должно переписывать исторические расчёты.
