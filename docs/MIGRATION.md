# Migration

Миграция старого Fingen должна быть отдельным слоем. Legacy-формат не должен проникать в domain/data model FingenNext.

Текущая Room schema migration:

- 1 → 2: перевод старого баланса счета в opening balance + ledger foundation;
- 2 → 3: добавление долгов и версионируемых шаблонов кредитных карт.

Импорт старых данных должен быть идемпотентным и иметь отчёт об ошибках по каждой записи.
